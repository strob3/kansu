# Third-Party Data Attribution

## OpenJLPT

This project uses Japanese language-learning data from **OpenJLPT**.

Source:
https://github.com/evanclan/OpenJLPT

License:
**Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**

License:
https://creativecommons.org/licenses/by-sa/4.0/

The OpenJLPT dataset includes JLPT vocabulary, kanji, and example sentences. OpenJLPT documents its upstream sources and attribution requirements in its `NOTICE.md`.

The OpenJLPT data used by this project has been imported into the project's local SQLite database.

Changes made to the data include transforming the source data into this project's database schema and associating vocabulary entries with kanji.

OpenJLPT is not affiliated with or endorsed by this project.
